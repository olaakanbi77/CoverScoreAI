# CoverScore Hospital Desktop & Mobile Funnel Design Brief

## Project Objective

Create a **Hospital/Healthcare version** of the existing CoverScore School landing pages.

**Important: This is NOT a redesign project.**

The School Desktop Funnel and School Mobile Funnel are the **master templates** and have already been optimized for conversion.

Your task is to **preserve the exact layout, spacing, section order, card sizes, and visual hierarchy** while replacing only industry-specific content.

---

# CRITICAL DESIGN RULE

## DO NOT CHANGE:

* Section order
* Overall page structure
* Component placement
* Card dimensions
* Padding and spacing relationships
* CTA placement
* Information hierarchy
* Footer structure
* Number of cards per section
* Visual density

## ONLY CHANGE:

* Copy/text
* Images
* Icons
* Calculator inputs
* Risk stories
* Sample report content
* Industry metrics
