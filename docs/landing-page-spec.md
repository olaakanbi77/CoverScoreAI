# CoverScore Personal™ Landing Page & Conversion Funnel Specification v1
Product Specification for the Family Protection Score™ Entry Funnel

Product: CoverScore Personal™
Primary offer: Free Family Protection Score™
Primary channel: Mobile web → WhatsApp
Primary objective: Start a WhatsApp assessment
Secondary objective: Attribute every lead to its source and campaign
Core principle: One page, one goal.

## 1. Purpose

The CoverScore Personal™ landing page is the entry point into the Family Protection Score™ journey.

It should help a visitor quickly understand:
* what CoverScore is,
* why the assessment matters,
* what they will receive,
* how long it takes,
* that it is private and free,
* and how to begin.

The page must not try to sell an insurance policy immediately.
Its only conversion goal is: Get the visitor to start the Family Protection Score™ assessment on WhatsApp.

## 3. Primary User
**Ideal Visitor**
A working adult, parent, household provider, entrepreneur, professional, or family decision-maker who wants to understand whether their household is financially and practically prepared for unexpected life events.

**Visitor Mindset**
The visitor may be thinking:
* What would happen if I could not work for a while?
* Would my family cope if something unexpected happened?
* Do I have enough health protection?
* How would school fees and household expenses continue?
* Am I actually prepared, or just hoping things will be fine?

The page should speak to these concerns calmly, respectfully, and without fear-based pressure.

## 4. Conversion Objective
**Primary CTA**
Start My Free Family Protection Score™

**CTA Destination**
WhatsApp with prefilled assessment keyword. Example structure:
`https://wa.me/[COVERSCORE_WHATSAPP_NUMBER]?text=FAMILY`

**CTA Rule**
Every major CTA on the page must lead to the same WhatsApp assessment entry point. Do not create competing actions such as Buy Insurance Now, Book a Call, Download a Brochure, Contact Sales, View Products. Those actions can appear only after the assessment and report journey.

## 6. Mobile-First Design Rules
* Design for a 390px-wide mobile screen first.
* One clear action per section.
* Use short paragraphs and scannable cards.
* Keep the primary CTA visible through a sticky bottom bar.
* Avoid dense comparison tables.
* Use large tap targets.
* Use one dominant accent color for CTAs.
* Use real-life risk imagery only where it supports understanding.
* Do not overload the page with insurance product details.
* Keep page load fast on mobile data networks.

## 19. CTA and Attribution Specification
**CTA Link Structure**
The CTA should open WhatsApp with a campaign-aware keyword.
`https://wa.me/[COVERSCORE_WHATSAPP_NUMBER]?text=FAMILY%20[CAMPAIGN_CODE]`
Example: `https://wa.me/2348012345678?text=FAMILY%20FB_JUNE_2026`

**Recommended Campaign Codes**
| Source | Campaign Code Example |
|--------|-----------------------|
| Facebook advert | FB_FAMILY_JUNE_2026 |
| Instagram advert | IG_FAMILY_JUNE_2026 |
| LinkedIn organic post | LI_FAMILY_JUNE_2026 |
| WhatsApp referral | WA_REF_FAMILY_2026 |
| QR code | QR_FAMILY_2026 |
| Website organic | WEB_FAMILY_2026 |

**Important WhatsApp Parsing Rule**
The WhatsApp Conversation Engine should accept:
`FAMILY`
`FAMILY FB_FAMILY_JUNE_2026`
`FAMILY IG_FAMILY_JUNE_2026`

It should:
1. Recognize FAMILY as the start command.
2. Extract the optional campaign code.
3. Save campaign code into source metadata.
4. Start or resume the assessment.

**Landing Page Tracking Fields**
Capture these fields before WhatsApp opens: `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`, `landing_page`, `cta_position`, `campaign_code`, `referral_code`, `device_type`, `timestamp`

**CTA Event Payload**
```json
{
  "event_name": "family_protection_cta_clicked",
  "landing_page": "coverscore_personal",
  "cta_position": "hero",
  "utm_source": "facebook",
  "utm_medium": "paid_social",
  "utm_campaign": "family_protection_june_2026",
  "utm_content": "video_ad_01",
  "campaign_code": "FB_FAMILY_JUNE_2026",
  "timestamp": "2026-06-24T14:00:00Z"
}
```

**Attribution Storage Rule**
When the WhatsApp session begins, store source information in: `leads.source_metadata`, `assessment_sessions.source_campaign`, `assessment_sessions.source_metadata`

## 21. Landing Page Data Model
Create a simple table for pre-WhatsApp CTA tracking.

```sql
CREATE TABLE landing_page_events (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  organization_id uuid REFERENCES organizations(id),
  session_key varchar(120),
  event_name varchar(100) NOT NULL,
  landing_page varchar(100) NOT NULL,
  cta_position varchar(80),
  utm_source varchar(120),
  utm_medium varchar(120),
  utm_campaign varchar(160),
  utm_content varchar(160),
  utm_term varchar(160),
  campaign_code varchar(120),
  referral_code varchar(120),
  device_type varchar(50),
  metadata jsonb NOT NULL DEFAULT '{}'::jsonb,
  created_at timestamptz NOT NULL DEFAULT now()
);

CREATE INDEX idx_landing_page_events_campaign
ON landing_page_events (utm_campaign, event_name, created_at);

CREATE INDEX idx_landing_page_events_session
ON landing_page_events (session_key, created_at);
```

**Session Key Rule**: Use a privacy-preserving anonymous browser session key. Do not require the visitor to enter a phone number on the landing page.

## 22. WhatsApp Entry Integration

**Landing Page to WhatsApp**
Visitor taps CTA → Landing page stores CTA event → Browser opens WhatsApp → Prefilled message contains FAMILY + campaign code → Evolution API receives message → Node-RED extracts campaign code → Lead and assessment session are created → Attribution is saved

**Node-RED Parser Update**
Update the command parser to support optional campaign codes.
```javascript
const text = msg.coverscore.text_normalized.trim();
const match = text.match(/^FAMILY(?:\s+([A-Z0-9_:-]+))?$/);

if (match) {
    msg.coverscore.route = 'command_start';
    msg.coverscore.campaign_code = match[1] || null;
    return msg;
}
```

**Source Attribution Mapping**
* Campaign code starts with FB_ → facebook
* Campaign code starts with IG_ → instagram
* Campaign code starts with LI_ → linkedin
* Campaign code starts with QR_ → qr_code
* Campaign code starts with WA_ → whatsapp_referral
* Campaign code starts with WEB_ → website
