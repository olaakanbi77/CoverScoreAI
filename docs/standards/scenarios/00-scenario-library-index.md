## Master template

SR-001 is the **master reference simulation**. SR-002 to SR-010 are produced from the SR-001 template so all ten scenarios are consistent and certification-ready.

## Usage rules

1. In certification, the assessor selects one scenario at random.
2. Candidates receive only the Advisor Brief, Report, client profile, and CRM notes.
3. The Advisor Brief is confidential and never shown to the (simulated) client.
4. Scoring uses the 100-point Simulation Framework.
5. Critical failure conditions apply to every scenario.
