## 2. Slide Production Notes

Use the shared master template and design language from the CCA 105 production pack
(colours, type, contrast, one-idea-per-slide rule). Diagrams reused across the programme
(process flow, matrices, arcs, band colours) keep recognition high. Score-band colour
lock (canonical): Highly Resilient = green; Moderately Resilient = light green/teal;
Needs Improvement = amber; High Risk = deep red; Critical Risk = darkest red.

## 4. Animations

| # | Animation | Behaviour |
|---|-----------|-----------|
| A1 | CARE™ stage lighting | Stages light in sequence C→A→R→E; never scrambled |
| A2 | Seller vs Advisor contrast | Side-by-side; advisor side highlights |
| A3 | Listening sequence | Cards appear one at a time then loop |
| A4 | Two funnels | Old funnel collapses; CoverScore funnel grows |
| A5 | Flywheel | Spins slowly; stops on each stage label |
| A6 | Life cycle | 8 stages advance along the timeline |
| A7 | Report → Opportunity | Insight node flows through conversation → discovery → opportunity |
| A8 | Operating model | Full AI/Advisor flow animates left to right |

**Motion rules:** 300–500 ms transitions; no flashing; honour reduced-motion; urgency
cues never strobe (ethics + accessibility).
