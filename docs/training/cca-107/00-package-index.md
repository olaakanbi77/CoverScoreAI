## Module Identity

- **Position in the Academy:** CCA 105 interprets the intelligence → CCA 106 uses the
  intelligence → **CCA 107 manages the relationship and the client risk portfolio** →
  CCA 108 demonstrates the complete advisory cycle.
- **Central question:** How do I continuously create value for this client?
- **Core principle:** A policy is a transaction. A portfolio is a relationship.
- **Theme:** client risk portfolios, portfolio monitoring and continuous risk
  intelligence, annual reassessments and resilience reviews, professional CoverScore Risk
  Reviews™, claims and post-loss advisory, documentation and CRM, client value and advisor
  performance, and the portfolio-management simulation.

## How To Use This Package

1. **Producers / course creators** — Start with `01-module-blueprint.md`, then produce
   lessons in sequence using the fixed 12-section template in each lesson file and the
   `06-multimedia` production pack.
2. **Instructors** — Use `03-resources/01-instructor-guide.md` to run monitoring drills,
   Risk Review™ practice, and the Lesson 8 portfolio simulation, supported by
   `03-resources/05-conversation-guides.md`.
3. **Learners** — Work through Lessons 1–8 using the Learner Handbook section in each
   lesson and `03-resources/02-student-workbook.md`.
4. **AI systems** — Load the prompts in `05-ai-companion` into the AI Tutor, AI Coach,
   AI feedback and AI grading engines. The per-lesson Knowledge Base entries live inside
   each lesson file.
5. **Assessors** — Run the assessment pack in `04-assessment/assessment-pack.md`: the
   Portfolio Management Simulation scored on the 100-point, 8-part model.

## Terminology Reference (used across this package)

| Term | Meaning |
|------|---------|
| CoverScore™ | The 0–100 overall risk score from the assessment engine |
| CoverScore Report™ / Risk Story™ | The client-facing output after scoring |
| Advisor Brief™ | One-page AI-generated briefing given to the advisor |
| CARE™ | The canonical conversation framework: Connect → Ask → Reframe → Enable |
| Risk Review | The structured meeting where the advisor walks the client through the report |
| Portfolio | The client relationship across all exposures and across time |
| Continuous Risk Intelligence | New information flowing into risk change signals that drive advisor action |
| Client Value Score | Risk Improvement 30 · Relationship Health 20 · Retention 20 · Engagement 15 · Growth 15 |
| Post-Loss Framework | Stabilise → Document → Understand → Learn → Improve → Protect |
| Four-Response Model | Reduce / Transfer / Accept / Avoid |
| CRM Discipline | Every engagement answers Who? What? Why? When? Decision? Next step? |

Score bands used in the platform (canonical, per the Intelligence Standards™):
**Highly Resilient** (80–100), **Moderately Resilient** (60–79), **Needs Improvement**
(40–59), **High Risk** (20–39), **Critical Risk** (0–19).

Advisory workflow (canonical): the **10-step workflow** — Receive, Review, Prepare,
Discover, Interpret, Prioritise, Advise, Agree, Document, Follow Through. Risk
Reduction™ is always presented before Risk Transfer™, and the two are never mixed.

## Certification Standard (recap)

The certification instrument is the **Portfolio Management Simulation** scored on
8 parts (Portfolio Management 15, Continuous Risk Intelligence 10, Resilience Reviews 15,
Professional Risk Review 15, Claims & Post-Loss Advisory 10, CRM & Documentation 10,
Client Value 10, Portfolio Simulation 15). Pass bands: 80–100 Competent · 70–79
Conditional Pass · 60–69 Remediation Required · below 60 Not Yet Competent. Full detail in
`04-assessment/assessment-pack.md`.
