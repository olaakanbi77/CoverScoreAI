# CCA 107 — Instructor Guide (Part 3)

**Module:** CCA 107 — Professional Risk Advisory Practice & Client Portfolio Management

## 1. Your Role

You are the instructor for the module that turns a client relationship into a managed
risk portfolio. Your job is to model portfolio stewardship: monitoring, reassessment,
professional Risk Reviews™, post-loss advisory, documentation, and value measurement.
Learners enter with CCA 106 "use the intelligence" skills; you take them to "manage the
relationship" (CCA 107) before they move to "demonstrate the complete advisory cycle"
(CCA 108). Keep the module principle on the wall: **a policy is a transaction, a
portfolio is a relationship.**

## 3. Room Setup

- Breakout triads: one advisor, one client, one observer/scorekeeper rotating each round.
- Shared artefacts: portfolio principle poster, monitoring cadence card, seven-stage Risk
  Review™ diagram, post-loss framework poster, critical-failure poster, Flourish College
  review-cycle pack.
- Strict timekeeping for the 15-minute portfolio review; observers record stage
  transitions.
- A "stop" signal for critical failures, so a learner who raises products before
  understanding the exposure can restart and learn in the moment.

## 4. Facilitation Script (debrief template)

After every simulation or role-play, run the same five questions:

1. What did the Advisor do well? (name it specifically)
2. Which review stages appeared, in order? Which were skipped or rushed?
3. How was each piece of new information reconciled against the current portfolio?
4. Did the Advisor prioritise reduction before transfer — and document the outcome?
5. What is the one thing to change for the next round?

Use the critical-failure list to highlight moments that would fail the assessment.

## 5. Common Learner Errors and Coaching

| Error | Coaching intervention |
|-------|------------------------|
| Treats the review as a renewal ritual | Replay the portfolio principle; rebuild the review as progress + gaps |
| Ignores the student accident | Stop the scene; run the post-loss response (acknowledge, care, then risk story) |
| Ignores the unresolved transport procedures | Re-read Lesson 2's monitoring cadence; name the unresolved high-priority gap |
| Raises products before understanding exposure | Demand Discover and Interpret first; apply the four-response model |
| Lets the improved score hide remaining gaps | Rehearse the progress-and-gaps interpretation of 41 → 58 |
| Assures the client everything is covered | Drill the reconciliation: "The portfolio was built for the school as it was last year." |
| Does not document or agree next steps | Enforce the six-question CRM discipline; make documentation part of every scene |
| Blames the client after an incident | Replay Lesson 5's blame-free response; stabilise before advising |

## 6. Assessment Logistics

Use the module assessment in `04-assessment/assessment-pack.md`. Book one-on-one 15-minute
Portfolio Management Simulations (assessor plays Florence James and reveals the year's
changes only through the learner's questioning). Score the 8-part rubric, flag any
critical failure, and provide feedback within 48 hours. Conditional passes (70–79)
re-assess only the weakest part; a critical failure always mandates coaching.
