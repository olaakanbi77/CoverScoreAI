## 4. Animations

| # | Animation | Behaviour |
|---|-----------|-----------|
| A1 | Policy vs Portfolio | Two objects: policy fades as a one-time transaction; portfolio grows as an enduring relationship |
| A2 | Continuous-intelligence flow | Client → new info → intelligence → signal → review → engagement flows left to right, then loops |
| A3 | Cadence lighting | High-priority glows frequently; standard periodically; stable on schedule |
| A4 | Score progress arc | 41 rises to 58 while a separate gap counter stays visible |
| A5 | Seven-stage bar | Stages light in order Prepare → Open → Discover → Interpret → Advise → Document → Next Action; never scrambled |
| A6 | Post-loss framework | Six stages advance one at a time; never starts at a product |
| A7 | BAD vs GOOD notes | BAD note redacts; GOOD note grows with facts, implications, priorities, next action |
| A8 | Portfolio principle reveal | "A POLICY IS A TRANSACTION" appears, then "A PORTFOLIO IS A RELATIONSHIP" |

**Motion rules:** 300–500 ms transitions; no flashing; honour reduced-motion; urgency
cues never strobe (ethics + accessibility).
