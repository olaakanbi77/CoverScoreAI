## Module Identity

- **Position in the Academy:** CCA 101–104 build knowledge and mindset → CCA 105
  interprets the intelligence → CCA 106 uses the intelligence → CCA 107 manages the
  relationship. **CCA 108 is the final stage: demonstrate professional competence.**
- **Central question:** Can the learner independently perform as a professional
  CoverScore Risk Advisor in a complex, realistic client environment?
- **Capstone principle:** *Knowledge is not competence. Competence is the ability to
  apply knowledge correctly in a real situation.*
- **Capstone rule:** *Do not sell because you found a product. Advise because you found a
  need.*
- **Theme:** complete integration of CCA 101–107 into assessed, real-world advisory
  performance — from discovery through portfolio management and into a sustainable
  long-term relationship.
- **Final professional principle:** *AI can identify the risk. You must understand the
  person behind the risk.*

## How To Use This Package

1. **Producers / course creators** — Start with `01-module-blueprint.md`, then produce
   lessons in sequence using the fixed 12-section template in each lesson file and the
   `06-multimedia` production pack.
2. **Instructors** — Use `03-resources/01-instructor-guide.md` to run the simulation
   workshops and the Lesson 8 final case, supported by `03-resources/05-conversation-guides.md`.
3. **Learners** — Work through Lessons 1–8 using the Learner Handbook section in each
   lesson and `03-resources/02-student-workbook.md`.
4. **AI systems** — Load the prompts in `05-ai-companion` into the AI Tutor, AI Coach,
   AI feedback and AI grading engines. The per-lesson Knowledge Base entries live inside
   each lesson file.
5. **Assessors** — Run the assessment pack in `04-assessment/assessment-pack.md`: the
   final integrated simulation scored on the 10-part, 100-point model.

## Terminology Reference (used across this package)

| Term | Meaning |
|------|---------|
| CoverScore™ | The 0–100 overall risk score from the assessment engine |
| CoverScore Report™ / Risk Story™ | The client-facing output after scoring |
| Advisor Brief™ | One-page AI-generated briefing given to the advisor |
| CARE™ | The canonical conversation framework: Connect → Ask → Reframe → Enable |
| The Capstone | CCA 108 — the demonstration of professional capability |
| Capstone Rule | Do not sell because you found a product. Advise because you found a need. |
| Operating Model | AI discovers, assesses, generates intelligence, automates, reassesses; the Advisor interprets, advises, builds strategy, manages the long-term relationship |
| Four-Response Model | Avoid / Reduce / Transfer / Accept |
| Relevance Rule | Need → Conversation → Assessment → Advice → Solution (never Product → Pitch → Pressure) |
| The Professional Rule | AI is an intelligence source, not the professional decision-maker |

Score bands used in the platform (canonical, per the Intelligence Standards™):
**Highly Resilient** (80–100), **Moderately Resilient** (60–79), **Needs Improvement**
(40–59), **High Risk** (20–39), **Critical Risk** (0–19).

Advisory workflow (canonical): the **10-step workflow** — Receive, Review, Prepare,
Discover, Interpret, Prioritise, Advise, Agree, Document, Follow Through. Risk
Reduction™ is always presented before Risk Transfer™, and the two are never mixed.

## Certification Standard (recap)

The certification instrument is the **Final Integrated Advisory Simulation** — the Darman
Schools Group case — scored on 10 parts (Risk Intelligence 10, Professional Communication
10, Discovery & Client Understanding 10, CARE™ Framework 10, Professional Judgment 15,
Advisory Strategy 15, Business Development 10, Portfolio Management 10, Ethics &
Integrity 5, Documentation & Handoff 5) totalling 100 points. Pass bands: 85–100
Certified Advisor Ready · 75–84 Competent · 65–74 Conditional Pass · below 65 Not Yet
Competent. Any critical fail condition bars certification regardless of total score.
Full detail in `04-assessment/assessment-pack.md`.
