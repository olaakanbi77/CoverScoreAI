## Template 4 — Follow-up Planner

```
━━━ FOLLOW-UP PLANNER ━━━
Client: ____________  Last contact: ____________

| What | Why | Channel | When | Owner |
|------|-----|---------|------|-------|
| | | | | |

Engagement rhythm:
  • Day 0  — report delivered / review held
  • Day 3  — check-in on decision
  • Day 7  — proposal/plan sent (if agreed)
  • Day 14 — decision follow-up
  • Month 3 — implementation check
  • Month 6 — gap review
  • Month 12 — reassessment / annual review

CRM fields to log: next action, due date, status, notes.
```
