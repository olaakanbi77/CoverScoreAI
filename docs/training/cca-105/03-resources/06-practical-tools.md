# CCA 105 — Practical Tools (Part 3)

A compact toolkit to use during real engagements.

---

## Tool 1 — Pre-Engagement 15-Minute Sprint

When time is short, run 15 minutes in this order:
1. (3 min) Read the Advisor Brief highlights + score + band.
2. (3 min) Read the report's top 3 risks + strengths.
3. (3 min) Note confidence and 2 verification questions.
4. (2 min) Choose 3 questions from the bank.
5. (2 min) Personalise the opening line.
6. (2 min) Rehearse the opening aloud once.

## Tool 2 — The "So What?" Test

For any recommendation, ask: "If the client does nothing, what actually happens, in
plain money terms?" If you cannot answer with the client's own numbers, the
recommendation is not ready. Run it on all three priorities before every review.

## Tool 3 — The Two-Sentence Comfort Script

For nervous or sceptical clients:
> "I'm not here to sell you a policy today. I'm here so you understand your risks and
> choose one next step. You decide the pace everywhere — my job is to make your options
> clear."

Use at the open, and again if you sense cost anxiety.

## Tool 4 — The Trade-Off Card

When a client cannot act on everything, present trade-offs:
```
If we do [A] first → protects against [catastrophic gap] but [what we postpone].
If we do [B] first → protects the big losses slowly but [what we postpone].
Recommended: [A] — because [top catastrophic impact], then we revisit [B] next review.
```
Never let a client walk away believing inaction costs nothing: that is exactly the
"What happens if we don't fix it" line from the Client Action Plan.

## Tool 5 — The Follow-Up Rhythm Card

```
Day 0   Review held → decision + next step agreed → logged
Day 3   Check-in message ("how is [next step] going?")
Day 7   Proposal / plan sent if agreed
Day 14  Decision follow-up (respectful, not pushy)
Month 3  Implementation check
Month 6  Gap review
Month 12 Reassessment + annual review
```

## Tool 6 — Everyday Professional Language

Replace jargon with plain phrases (from Lesson 4):
- "CoverScore 46 — Needs Attention" → "46 out of 100 — partially protected today."
- "Protection gap" → "The cover you don't yet have."
- "Exposure index" → "What a major event could cost if unprotected."
- "Risk DNA / fingerprint" → "Your risk picture at a glance."

## Tool 7 — CRM Discipline Card

After every client interaction, before you close the screen:
1. Log the next action + due date.
2. Update the pipeline stage.
3. Save notes (facts, phrases, decisions).
4. Book the follow-up slot.
5. Flag the confidence level on the assessment.

## Tool 8 — Ethics Quick Check

Before every engagement ask:
- Am I recommending what this client needs, or what suits my quota?
- Am I using the client's own numbers, not invented ones?
- Have I respected their right to say no, and their pace?
- Would I be comfortable explaining this recommendation to a regulator or a judge?
