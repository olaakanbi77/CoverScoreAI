## How To Use This Package

1. **Producers / Course creators** — Start with `01-module-blueprint.md`, then produce
   lessons in sequence using the fixed lesson template in each lesson file and the
   `06-multimedia` production pack.
2. **Instructors** — Use `03-resources/01-instructor-guide.md` to run virtual workshops
   and simulations, supported by `03-resources/05-conversation-guides.md`.
3. **Learners** — Work through Lessons 1–8 using the Learner Handbook section in each
   lesson and `03-resources/02-student-workbook.md`.
4. **AI systems** — Load the prompts in `05-ai-companion` into the AI Tutor, AI Coach,
   AI feedback and AI grading engines. The per-lesson Knowledge Base entries live inside
   each lesson file.
5. **Assessors** — Run the assessment pack in `04-assessment/assessment-pack.md`, guided
   by the scoring rubric and certification standard.

## Terminology Reference (used across this package)

| Term | Meaning |
|------|---------|
| CoverScore™ | The 0–100 overall risk score from the assessment engine |
| CoverScore Assessment™ | The conversational (WhatsApp/web) risk questionnaire, run by the CCIE engine |
| CoverScore Report™ / Risk Intelligence Report™ | The client-facing report generated after scoring |
| Advisor Brief™ | One-page AI-generated briefing given to the advisor (Advisor Copilot output) |
| Risk Review | The structured meeting where the advisor walks the client through the report |
| Risk Fingerprint / Risk DNA | Patterns across risk dimensions that tell the interpretation story |
| Exposure Index | Estimated potential loss magnitude from identified gaps |
| Protection Gap | The difference between current protection and adequate protection |
| Opportunity Score | 0–100 commercial potential of the lead (Sales score in CRM) |
| AI Tutor | Guides understanding of concepts and knowledge |
| AI Coach | Guides practice and skill-building through prompts |
| CCIE | CoverScore Conversational Intelligence Engine (question flow & scoring) |

Score bands used in the platform (canonical, per the Intelligence Standards™):
**Highly Resilient** (80–100), **Moderately Resilient** (60–79), **Needs Improvement**
(40–59), **High Risk** (20–39), **Critical Risk** (0–19).

Advisory workflow (canonical): the **10-step workflow** — Receive, Review, Prepare,
Discover, Interpret, Prioritise, Advise, Agree, Document, Follow Through. Risk
Reduction™ is always presented before Risk Transfer™, and the two are never mixed.

## Certification Standard (recap)

Learners must demonstrate competence in assessment interpretation, report explanation,
discovery questioning, communication, professional judgement, risk prioritisation, and
client engagement — with a minimum pass mark of **80%**. Full detail in
`04-assessment/assessment-pack.md`.
